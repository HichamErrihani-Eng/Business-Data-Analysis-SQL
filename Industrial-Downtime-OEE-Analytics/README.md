# 🏭 Industrial Downtime & OEE Analytics

## Business Context
In a multi-site industrial environment (USA, Europe, Asia), production lines generate massive amounts of data. The challenge was to centralize this data and calculate reliable OEE metrics.

## Key Results
- Data reliability gap reduced from 8% to <1%
- Report generation time reduced from 45 min to <5 min
- Power BI adoption reached 80% of users

## Technical Stack
- SQL Server (T-SQL, Star Schema)
- Power BI (DAX, RLS)
- Azure Data Factory
